# 🧮 Calculadora Interativa em Python

Uma calculadora interativa desenvolvida em **Python** durante meus estudos de programação.

O programa permite que o usuário escolha diferentes operações matemáticas através de um menu e também permite inserir novos números sem precisar reiniciar a aplicação.

## 📌 Sobre o projeto

Este projeto foi desenvolvido para praticar conceitos fundamentais de **lógica de programação e Python**, principalmente estruturas de repetição, condicionais, entrada de dados e operações matemáticas.

A aplicação funciona diretamente pelo **terminal/console**, permitindo que o usuário interaja com um menu de opções.

## ⚙️ Funcionalidades

* ➕ Soma de dois números
* ✖️ Multiplicação de dois números
* 🔢 Verificação de qual número é maior
* 🔄 Inserção de novos números
* 🚪 Encerramento do programa através de uma opção de saída
* 🖥️ Interface interativa pelo terminal

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/calculadora-interativa-python.git
```

### 2. Entre na pasta do projeto

```bash
cd calculadora-interativa-python
```

### 3. Execute o arquivo Python

```bash
python calculadora.py
```
